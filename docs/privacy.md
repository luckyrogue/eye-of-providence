# Privacy

Краткая выжимка из README §8. Подробный документ — в Phase 5.

## Что НЕ покидает машину пользователя
- Содержимое файлов / промптов / ответов AI.
- Сами keystrokes (только counters).
- Заголовки приватных/incognito окон, окон из blacklist.
- Содержимое clipboard (только sha256 + размер).

## Что отправляется
- Метаданные событий (см. `proto/event.proto`).
- Числовые агрегаты для AI-отчётов (Gemini), без меток на содержимое.

## Local-only mode
Solo-пользователь может работать без backend — всё хранится в локальной SQLite.
